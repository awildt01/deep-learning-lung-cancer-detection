# 🫁 Lung Cancer Detection — 3D CNN auf LUNA16

Binäre Klassifizierung von Lungenknoten-Kandidaten aus CT-Scans mit einem 3D-CNN, trainiert auf dem [LUNA16-Datensatz](https://luna16.grand-challenge.org/).

**AUC = 0.987 | Recall = 93 % (127/136 echte Knoten erkannt)**
